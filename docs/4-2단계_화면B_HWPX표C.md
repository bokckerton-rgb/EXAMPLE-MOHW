# 4-2단계 · 주요 개정 연혁 보여주는 방식 바꾸기 (화면 B · HWPX C)

## 무엇이 바뀌었나
| 어디 | 전 | 후 |
|---|---|---|
| 강의실 「주요 개정 연혁」 | 날짜·조문 목록·선정 사유·별점 | **연도별로 묶고**, 분야 태그 + 짧은 제목 + `개정 전 → 개정 후` 줄 + 시행일·법률 번호·원문 링크 |
| 같은 법률이 시행일만 나뉜 경우 (예: 법률 제21489호 3.20/3.27) | 두 줄로 따로 | **한 카드로 합침** (줄마다 시행일 표시, 원문 링크는 시행일별로) |
| HWPX | 항목마다 문단 여러 개 | **표 한 장**: 시행일 · 분야 · 바뀐 내용 · 근거, 아래에 출처 URL 목록 |
| 검토 창 | 선정 사유만 | 분야 태그·전→후 줄도 미리 보임 |

## 파일
| 파일 | 내용 |
|---|---|
| `supabase/04_law_history_display.sql` | `law_history_items` 에 `areas`(분야)·`headline`(짧은 제목)·`changes`(전→후) 칸 추가, `confirm_law_history` 가 새 칸도 저장 |
| `supabase/functions/law-history-review/index.ts` | AI에게 분야·제목·전→후도 받도록 지시, 정해진 5개 분야 외 값·긴 글은 서버에서 잘라냄 |
| `web/mohw-handoff-v5.html` | 화면 B, HWPX 표 C (v4 를 이름만 바꿔 이어서 고침) |

## Example project 에 이미 반영한 것
- SQL 04 실행 완료 (기존 확정본 데이터는 그대로)
- `law-history-review` 다시 배포 완료

## 직접 해 볼 순서
1. `web/mohw-handoff-v5.html` 열기 → 아동수당 → 강사 검색 → 규제개혁법무담당관
2. 지금 확정본(제2판)은 새 칸이 없어서 **예전 내용(조문 요약·선정 사유)으로 대신** 보이고, 아래에 안내 문구가 나옵니다.
3. 「주요 개정 검토」 → 팀 코드·이름 → 「AI 추천 받기」 → 분야 태그·전→후 줄 확인 → 「연혁 확정」
4. 새 확정본(제3판)이 연도별 카드로 보이면 성공 → 「HWPX 다운로드」 → 한글에서 표가 열리는지 확인

## 확인 못 한 것
- 실제 한글 프로그램에서 표가 깨지지 않고 열리는지 (여기서는 ZIP·XML 구조만 검사)
- 무료 AI 모델이 분야·전→후를 얼마나 정확히 뽑는지 (서버는 형식만 검사, 내용 확인은 팀원 몫)
- 테스트 화면의 `[예시]` 문구는 가짜 값이며, 실제 내용은 AI 추천 → 팀원 확인 후에만 들어갑니다.
