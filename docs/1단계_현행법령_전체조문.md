# 아동수당법 전체 조문 붙이기 — 실행 순서

이번 단계 범위: **업무 등록 → 법제처 조회 → 전체 조문 표시**
(OpenRouter 중요도 판단, 주요 개정 최대 10건, HWPX 다운로드는 다음 단계)

## 0. 파일 목록

| 파일 | 하는 일 | 어디에 넣나 |
|---|---|---|
| `supabase/01_task_laws.sql` | 업무 `child-allowance` ↔ 아동수당법(`013103`) 연결 등록 | Supabase SQL Editor |
| `supabase/functions/law-fulltext/index.ts` | 서버 함수. 법제처에서 전체 조문을 받아 홈페이지에 전달 | Supabase Edge Functions |
| `web/mohw-handoff-v4.html` | 시연본 + 규제개혁법무담당관 강의실의 「현행 법령」 칸 | 지금 쓰는 HTML 대신 |
| `supabase/config.toml` | CLI로 배포하는 팀원만 사용 | GitHub 저장소의 `supabase/` 폴더 |

화면 흐름: 첫 화면 「시연 업무 → 아동수당」(또는 소속 부서 아동정책과 → 담당 업무 아동수당) → 「강사 검색」 → 청사 불 켜지는 화면 → 강사 카드 6개 중 **규제개혁법무담당관** → 강의실. 기존 칠판 「아동수당법이 걸어온 길」 **바로 아래**에 새 칸 「지금 시행 중인 아동수당법」이 생깁니다.

---

## 1. 법제처 인증값(OC) 준비 — 팀에서 한 명만

1. open.law.go.kr 에 로그인 → **OPEN API 신청** 화면에서 법령 **본문** 조회(시행일 법령 포함)가 신청돼 있는지 확인합니다.
2. OC 값은 신청할 때 쓴 **이메일의 @ 앞부분**입니다. (예: `hong123@korea.kr` → `hong123`)
3. 이 값은 **카톡·HTML·GitHub에 적지 말고**, 아래 3단계에서 Supabase에만 입력하세요.

## 2. SQL 넣기 (업무–법령 연결 등록)

1. Supabase 대시보드에서 프로젝트 선택
2. 왼쪽 메뉴 **SQL Editor** → **New query**(+)
3. `supabase/01_task_laws.sql` 내용을 통째로 붙여 넣고 오른쪽 아래 **Run**
4. 아래 결과 창에 `child-allowance | 013103 | 아동수당법` **한 줄**이 보이면 성공
   - 다시 Run 해도 줄이 늘지 않습니다(중복 방지).
   - 기존 `task_law_articles` 테이블은 건드리지 않습니다.
   - 확인: 왼쪽 메뉴 **Table Editor** → `task_laws` 에서 law_id가 `13103`이 아니라 **`013103`**인지 보세요.

## 3. 인증값 등록 (서버 설정)

1. 왼쪽 메뉴 **Edge Functions** → 위쪽 탭 **Secrets**
   (안 보이면 **Project Settings → Edge Functions → Secrets**)
2. **Add new secret**
   - Name: `LAW_OC`
   - Value: 1단계의 OC 값
3. **Save**. 함수를 다시 배포할 필요는 없습니다.

## 4. 함수 배포

### 방법 A — 대시보드(개발 도구 없이)
1. 왼쪽 메뉴 **Edge Functions** → **Deploy a new function** → **Via Editor**
2. 함수 이름: `law-fulltext` (정확히 이 이름)
3. 편집기의 기본 코드를 모두 지우고 `supabase/functions/law-fulltext/index.ts` 내용을 붙여 넣기 → **Deploy function**
4. 배포 후 함수 화면의 **Details**(또는 Settings) 탭에서 **Verify JWT with legacy secret**(JWT 검증)를 **끄고** 저장
   - 이유: 홈페이지는 공개 키로 부르기 때문. 대신 함수 코드가 "이 프로젝트의 공개 키인지"를 직접 확인합니다.
5. 같은 화면의 **Endpoint URL**(`https://○○○.supabase.co/functions/v1/law-fulltext`)을 복사해 둡니다.

### 방법 B — 터미널(개발자 팀원)
```bash
# 저장소 안에 supabase/functions/law-fulltext/index.ts, supabase/config.toml 배치 후
supabase login
supabase link --project-ref <프로젝트-ref>
supabase secrets set LAW_OC=<OC값>          # 셸 기록에 남지 않게 주의
supabase functions deploy law-fulltext --no-verify-jwt
```

## 5. HTML에서 고칠 설정값 (두 줄)

`web/mohw-handoff-v4.html`을 메모장/VS Code로 열고 `LAW_API_CONFIG`를 찾습니다(Ctrl+F).

```js
const LAW_API_CONFIG = {
  functionUrl: 'https://YOUR-PROJECT-REF.supabase.co/functions/v1/law-fulltext',  // ← 4단계 Endpoint URL
  publishableKey: 'YOUR-SUPABASE-PUBLISHABLE-KEY'                                   // ← 아래 공개 키
};
```
- 공개 키: **Project Settings → API Keys** → **Publishable key**(`sb_publishable_…`). 새 키가 없는 프로젝트라면 **Legacy API Keys** 탭의 `anon` 키도 됩니다.
- **넣으면 안 되는 것**: `sb_secret_…`, `service_role` 키, 법제처 OC.
- 업무 ID 연결은 바로 아래 `TASK_LAW_LINKS`에 있습니다. 기존 HTML에는 아동수당 전용 ID가 없어서 `child-allowance`를 썼습니다.

## 6. 확인하는 법

| 확인 | 방법 | 정상 모습 |
|---|---|---|
| 화면 | HTML 열기 → 아동수당 → 강사 검색 → 규제개혁법무담당관 | 「불러오는 중」 잠깐 → 법령명·시행일·공포·조회 시각 → **전체 조문 보기** 누르면 조·항·호·목이 들여쓰기로 펼쳐짐 |
| 원문 링크 | 「국가법령정보센터 원문 ↗」 클릭 | law.go.kr 아동수당법 현행 화면 |
| 서버 기록 | Supabase **Edge Functions → law-fulltext → Logs / Invocations** | 상태 200 |
| 브라우저 기록 | 강의실에서 F12 → **Network** 탭 → `law-fulltext` | 상태 200, 응답에 `"ok": true` |
| 인증값 노출 | F12 Network 응답, HTML, GitHub 검색 | OC 값이 어디에도 없음 |

터미널이 있는 팀원은 직접 호출도 가능합니다:
```bash
curl -s -X POST '<Endpoint URL>' -H 'apikey: <Publishable key>' -H 'Content-Type: application/json' -d '{"taskId":"child-allowance"}' | head -c 600
```

### 오류 문구별 조치
| 화면 문구 | 원인 / 조치 |
|---|---|
| 홈페이지 설정값이 아직 비어 있어요 | 5단계 두 줄 미입력 |
| Supabase가 요청을 거절했어요(401) | 4단계의 JWT 검증 끄기 미적용, 또는 공개 키가 다른 프로젝트 것 |
| law-fulltext 함수를 찾지 못했어요 | 함수 이름·주소 오타, 배포 안 됨 |
| 서버에 법제처 인증값(LAW_OC)이 등록되지 않았어요 | 3단계 미완료(이름이 정확히 `LAW_OC`인지) |
| 연결된 법령이 없어요 / task_laws 테이블을 찾지 못했어요 | 2단계 SQL 미실행 |
| 법제처가 법령 대신 안내 페이지를 보냈어요 / 조문이 없어요 | OC 값 오타, 또는 open.law.go.kr에서 본문 API 미신청 |
| 연결하지 못했어요 / 20초 안에 응답이 오지 않았어요 | 일시 장애. 「다시 불러오기」 |

어떤 오류가 나도 위쪽 강의·칠판·다른 강사 화면은 그대로 동작합니다.

## 7. 알아 둘 점
- 같은 법령은 서버가 **10분** 동안 보관해 법제처 호출을 줄입니다. 응답의 `cached: true`가 그 표시이고, 「조회 시각」은 실제로 법제처에서 받은 시각입니다.
- 응답 JSON 구조(다음 단계에서 활용): `laws[].articles[]` = 장·절 제목(`kind: heading`) 또는 조문(`kind: article`, `label`, `title`, `text`, `deleted`, `paragraphs[] → hos[] → moks[]`). 전체 조문에는 개수 제한이 없고, "최대 10건"은 다음 단계의 주요 개정 목록에만 적용할 예정입니다.
- 시행일이 오늘 이후인 본문이 오면 「시행예정본」 표시가 붙습니다.
