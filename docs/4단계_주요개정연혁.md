## 화면 흐름 (HTML 하단에 별도 화면 없음)
첫 화면 → 아동수당 → 강사 검색 → **규제개혁법무담당관** 강의실 →
기존 칠판 아래 **① 주요 개정 연혁**(확정본, 시행일순, 시행 전이면 「시행 예정」) → **② 지금 시행 중인 아동수당법**(전체 조문 · 법령 새로고침)

- 「주요 개정 검토」(팀원) → 팀 코드·이름 → 「AI 추천 받기」 → 선정 사유·개정 전후 근거·원문 링크 확인 → 체크로 선택/제외 → 「연혁 확정」
- 「HWPX 다운로드」 → 화면의 같은 확정본(항목·순서·날짜·출처)을 브라우저에서 바로 HWPX로. AI·서버 호출 없음
- 「법령 새로고침」 → `law-fulltext` 로 현행 조문·마지막 조회 시각만 갱신(1분 안에 다시 누르면 보관본). 자동 갱신 없음

## 보안·데이터 규칙
- OpenRouter 키·팀 코드는 Supabase Secrets 에만. HTML·GitHub에는 공개 키(publishable)와 함수 주소만 있음
- 검토·확정·후보 수집은 서버가 팀 코드(`TEAM_REVIEW_CODE`)를 확인. 확정 연혁 읽기만 공개 키로 가능
- AI에는 실제 후보 ID와 바뀐 조문·부칙 전후 문구만 보냄. 응답의 없는 ID·중복 ID·10건 초과는 서버에서 제거
- 공포일·시행일·공포번호·원문 링크는 후보 표(법제처 값)에서만 가져와 확정본에 복사 저장
- 확정은 DB 함수 하나로 한 번에 저장(전부 성공 또는 전부 취소). OpenRouter·저장 실패 시 기존 현재 판 유지
- 판(version)은 계속 쌓이고 `is_current` 하나만 화면·HWPX에 쓰임

## 테스트 순서 (실제 개정 후보 1건: 2026.6.9 공포 · 2026.9.10 시행 · 제10조의2 신설)

### 준비 (한 번)
1. **Edge Functions → Secrets** 에 추가
   - `TEAM_REVIEW_CODE` = 팀원끼리 공유할 코드(6자 이상) ← **아직 없음, 직접 등록 필요**
   - `OPENROUTER_MODEL` = (선택) 예: `openrouter/free`. 비우면 `openrouter/auto`
   - `OPENROUTER_API_KEY`, `LAW_OC` 는 이미 등록됨
2. `web/mohw-handoff-v4.html` 을 브라우저로 열기 (설정값은 Example project 로 채워져 있음)

### ① 추천
1. 아동수당 → 강사 검색 → 규제개혁법무담당관
2. 「주요 개정 연혁」에 *아직 확정된 주요 개정 연혁이 없어요* 가 보이고 HWPX 다운로드가 비활성인지 확인
3. 「주요 개정 검토」 → 팀 코드·검토자 이름 입력 → 「AI 추천 받기」 (1~2분)
4. **성공 기준**: 추천 목록에 `2026. 9. 10. 시행 · 제10조의2 신설` 항목이 있고(모델 판단이라 다른 개정과 함께 나올 수 있음), 「개정 전후 근거 보기」에 개정 전 *(없던 조문)* / 개정 후 *제10조의2(첫만남이용권 지급)…* 와 *부칙 <제21777호…>*, 원문 링크가 보임
   - 확인 SQL: `select status, model, jsonb_array_length(recommendations) n, dropped from law_revision_reviews order by created_at desc limit 1;`

### ② 팀원 확정 (1건만)
1. 제10조의2 항목만 체크를 남기고 나머지는 해제 → 「연혁 확정 (1건)」
2. **성공 기준**: *확정본 제1판(1건)을 저장했어요*, 목록에 1건
   - 확인 SQL:
```sql
select c.version_no, c.is_current, c.confirmed_by, i.effective_date, i.promulgation_date, i.promulgation_no, i.changed_summary, i.source_url
from law_history_confirmations c join law_history_items i on i.confirmation_id = c.id
where c.task_id = 'child-allowance' order by c.version_no desc, i.sort_order;
```
   기대: `1 | true | <이름> | 2026-09-10 | 2026-06-09 | 21777 | 제10조의2 신설 | https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=286729&efYd=20260910`

### ③ 강의실 표시
1. 「처음으로」 → 다시 규제개혁법무담당관 강의실
2. **성공 기준**: 같은 1건이 `2026. 9. 10. 시행 · 1. 제10조의2 신설 · 타법개정 · 법률 제21777호 · 2026. 6. 9. 공포` 로 보이고, 원문 링크가 법률 제21777호 화면을 엶. (시행예정 개정 2027.1.21 을 확정하면 그 항목에만 「시행 예정」)

### ④ HWPX 다운로드
1. 「HWPX 다운로드」 → `아동수당법_주요개정연혁_제1판_YYYYMMDD.hwpx`
2. 한글에서 열기 → 제목 *아동수당법 주요 개정 연혁*, 확정본 제1판 정보, 항목 1건(시행일·개정·선정 사유·중요도·출처 URL), 맨 아래 출처 안내
3. 글자를 고쳐 저장해 보기(편집 가능 확인)
4. 브라우저 개발자 도구 Network 탭에서 다운로드 때 `law-history-review` 호출이 **없는지** 확인

### 실패해도 기존 연혁이 남는지
- 팀 코드를 틀리게 → *팀 코드가 맞지 않아요… 기존 확정 연혁은 그대로예요*
- Secrets 의 `OPENROUTER_MODEL` 을 없는 이름으로 바꿔 검토 → 오류 문구, 확정본 제1판 그대로 (확인 후 원래대로)
